# Spec — odin-gdk-pixbuf

## Packages

```
gdkpixbuf/   package gdkpixbuf: generated by runic from gdkpixbuf/rune.yml
```

Import through the `pixbuf` collection: `import "pixbuf:<package>"`.

## Surface

Every public declaration of the bound headers (gdk-pixbuf 2.42.10), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
